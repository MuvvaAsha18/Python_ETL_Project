# Employee ETL Pipeline

A Python ETL (Extract, Transform, Load) project that processes employee data from CSV files, transforms it into useful summaries, and saves the results into clean output files.  
This project demonstrates core data engineering concepts using Python.

---

## 📊 Dataset Source
The dataset used in this project was obtained from [Kaggle](https://www.kaggle.com).  
It contains synthetic employee records including job titles, departments, and demographic details.  
The data is used solely for educational and demonstration purposes.

---

## 🚀 Features
- **Extract**: Reads employee data from CSV files using Python’s built‑in `csv` module.  
- **Transform**:  
  - Aggregates job role counts.  
  - Calculates total male and female employees.  
- **Load**: Saves summaries into new CSV files for easy analysis.
